# Проверка реализации истории метрик

Дата: 2026-10-02. Проверки выполнены в отдельном локальном Docker-контейнере,
с временной SQLite базой. Удалённый сервер и его данные не использовались.

## Результат

- 16 выбранных backend-тестов прошли: `test_metrics_history.py`,
  `test_proxy_metrics_version_zero.py`, `test_internal_chat_proxy.py`.
- 5 frontend-тестов прошли: `model-performance.test.tsx`, `dashboard.test.tsx`.
- Frontend: TypeScript и production build прошли.
- Ruff для изменённых Python-модулей и новых тестов прошёл.
- ESLint для изменённых frontend-файлов прошёл; `git diff --check` прошёл.

Проверены миграция базы с 0004, сохранность старого журнала, повторный запуск
миграций, конкурентное создание клиента и накопление IP, одна запись на
streaming-запрос, сохранение исходного PID, TTFT первого содержательного chunk,
usage/cache/draft и native timings. Проверены очистка только снимков, работа
сборщика без браузера для двух профилей с повторной записью через 5 секунд,
восстановление extrema, свежий Prometheus и переход к SQLite при stale.
Проверен настоящий lifespan приложения с миграцией и HTTP endpoints истории.
График проверен на лимит 120 точек, восстановление, соединение разрывов,
значение наведённой точки и отсутствие повторной загрузки истории при live.

## Ограничения общего набора проверок

Полный набор проекта не объявляется зелёным. Общий ESLint сообщает существующие
ошибки в `models.tsx` (неиспользуемый StatusBadge) и `logs-drawer.tsx` (fast refresh).
Mypy дополнительно проходит по зависимым модулям и сообщает существующие ошибки
в `external_logs.py`, `engines/service.py`, `models/catalogue.py`.

Дополнительный запуск старых `test_review_findings_version_zero.py` и
`test_app_integration_version_zero.py` выявил несовпадения старых контрактов:
ожидание исключения для недоступного внешнего лога, ожидание `/v1/models` на
порту управления, одинаковые PORT/OPENAI_PORT и фиктивная миграция без создания
таблиц. Новый startup теперь обращается к журналу для восстановления прерванных
запросов, поэтому такой mock миграции не обеспечивает необходимые условия.
Реальный startup и миграции проверены отдельно без этого mock.

Работа с установленными GPU-движками и живым удалённым Prometheus не проверялась.
Их отсутствие не заменяется выдуманными измерениями; недоступные значения NULL.

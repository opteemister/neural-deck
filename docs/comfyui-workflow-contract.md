# Контракт API-workflow ComfyUI для NeuralDeck — ND.v1

Дата: 2026-10-29. Решение владельца: workflow — чёрный ящик с именованными
входами и выходом. Обратная совместимость со старыми графами не требуется.

## 1. Граница ответственности

NeuralDeck выбирает сохранённый workflow по алиасу и операции, подготавливает
входные параметры, загружает файлы, подставляет значения в контрактные входы
и отправляет **полный граф** в штатный `POST /prompt` ComfyUI. Получает статус
и файлы результата из истории задания. Внешние OpenAI endpoint, чат и MCP
используют один прикладной путь.

NeuralDeck не анализирует связи, ветви, зависимости, sampler, модель,
параллельность, OUTPUT_NODE или схему классов `/object_info`. Не ограничивает
исполнение через partial_execution_targets. Не проверяет defaults графа,
пиксели, прозрачность, размеры или количество полученных файлов, контейнер
и кодек видео. Не требует конкретного класса узла сохранения.

Автор workflow отвечает за выполнение параметров, обработку маски,
детерминизм seed, batching, формулу кадров, FPS, реальные размеры, фон,
формат и содержание результата. Параллельные и независимые ветви разрешены;
способ их выполнения определяет ComfyUI. Изменение лимитов или замена графа
не блокируются сравнением с прежней конфигурацией.

Нельзя добавлять в NeuralDeck модельные эвристики, угадывание входов,
исправление conditioning, resize, композиции или промпта. Старый Qwen-путь
удалён; граф без входов ND.v1 больше не поддерживается. Автоматического
преобразования старых графов или конфигураций нет.

## 2. Формат запроса и именованные входы

Workflow предоставляется как штатный API-экспорт: словарь узлов с
`class_type`, `inputs` и `_meta`. Экспорт редактора `nodes`/`links`
не преобразуется NeuralDeck в исполняемый граф. Чтение — через API userdata
ComfyUI; локальные папки и копии файлов NeuralDeck не использует.

Назначение входа задаёт точная метка `_meta.title`. Числовые ID произвольны.
Адаптер использует только метку и имя изменяемого поля; класс узла и его
внутреннее устройство не проверяются.

| Метка | Изменяемый вход | Единицы / значение |
| --- | --- | --- |
| `ND.v1.prompt` | `value` | Полный промпт |
| `ND.v1.width` | `value` | Итоговая ширина, px |
| `ND.v1.height` | `value` | Итоговая высота, px |
| `ND.v1.seconds` | `value` | Целые секунды видео |
| `ND.v1.n` | `value` | Количество отдельных изображений |
| `ND.v1.seed` | Ровно одно из `noise_seed`, `seed`, `value` | Seed генерации |
| `ND.v1.image` | `image` | Имя загруженного исходника в ComfyUI |
| `ND.v1.mask` | `image` | Имя загруженной маски в ComfyUI |
| `ND.v1.background` | `value` | `auto`, `opaque`, `transparent` |
| `ND.v1.output` | Не изменяется | Узел, из которого читать конечные файлы истории |

Рекомендуемые штатные входы: PrimitiveString/PrimitiveStringMultiline,
PrimitiveInt, LoadImage, LoadImageMask; seed — RandomNoise или sampler.
Это рекомендации автору графа, не список разрешённых классов адаптера.

Каждая метка уникальна. Отсутствующий обязательный вход, неоднозначная метка
или отсутствие ожидаемого поля — ошибка входного контракта: NeuralDeck
не может подготовить запрос. Связанность узлов и значения их defaults
адаптер не исследует. Назначение маски и её alpha-канала обеспечивает граф.

## 3. Операции

| Алиас / операция | Обязательные метки без префикса `ND.v1.` |
| --- | --- |
| image / generate | prompt, width, height, seed, output |
| image / edit | prompt, image, width, height, seed, output |
| image / edit_masked | prompt, image, mask, width, height, seed, output |
| image / variations | image, width, height, seed, output |
| video / generate | prompt, width, height, seconds, seed, output |
| video / edit | prompt, image, width, height, seconds, seed, output |

`n` нужен для передачи количества больше одного. Без входа поддерживается n=1. `prompt` для variations необязателен.
Видео generate — T2V, edit — I2V по одному исходному изображению. Реализацию
этого назначения обеспечивает автор workflow; NeuralDeck не ищет first_frame
или сохранённые LoadImage внутри графа.

API image, input_reference/reference отображаются на `ND.v1.image`.
Передаются одна исходная картинка и, для edit_masked, одна маска.
Несколько reference, last-frame и video remix этим контрактом не определены.

## 4. Параметры и defaults

- `size=WIDTHxHEIGHT` раскладывается в width/height; явные размеры положительны.
- Отсутствующее значение или `size=auto` оставляет defaults workflow.
  В том числе width=height=0 может быть внутренним сигналом auto-size.
  NeuralDeck не интерпретирует и не проверяет такие defaults.
- Отсутствующий/null seed: один новый случайный неотрицательный seed на запрос. Явный 0 остаётся фиксированным. Воспроизводимость всех
  стадий обеспечивает автор workflow.
- `quality=auto|low|medium|high` использует сохранённый native-режим как auto;
  значение не меняет шаги, размер или внутренние настройки. Режим исполнения определяет workflow. Другие quality возвращают 400.
- Background подставляется в именованный вход. Без него auto/opaque используют
  native-фон, а transparent не объявляется поддержанным.
- Файлы загружаются в ComfyUI; их полученные имена подставляются в image/mask.
- seconds → кадры, resize, alpha и сохранение области вне маски выполняет граф.

## 5. Настройки NeuralDeck — вне контракта workflow

Пользователь или агент задаёт только минимальные сведения об алиасе:

| Тип алиаса | Настройки |
| --- | --- |
| image | `max_megapixels` — бюджет изображения в МП |
| video | `max_resolution` — короткая сторона в px; `max_seconds` — длительность в секундах |

Эти поля видны непосредственно в форме алиаса, без сворачиваемого блока,
и доступны в API/MCP. Значения положительны, разрешение и секунды целые.
При создании они задаются явно; код не подставляет модельные максимумы.
Их нельзя заменять расширенной таблицей ограничений ни в UI, ни внутри кода.

Настройки нужны только NeuralDeck для расчёта пресетов и проверки отправляемых
размера/длительности. В граф и запрос ComfyUI эти настройки не передаются.
Workflow получает только выбранные фактические значения width, height и seconds.

Изображения: обычный размер использует половину бюджета площади, максимальный —
весь бюджет. Сохраняется принятая в приложении единица МП = 1024 × 1024 px.
Для отношения сторон r ширина = floor(sqrt(площадь × r)), высота =
floor(sqrt(площадь / r)). Видео: длинная сторона вычисляется из короткой
и выбранных пользователем пропорций. Варианты разрешения и длительности —
доли 1/3, 2/3 и 1 от соответствующего максимума, с округлением до целого.
Это политика пресетов UI, не ограничения модели.

Нет отдельных width/height min/max, кратности, min_seconds, max_n или
настраиваемого диапазона seed. Нет скрытого бюджета/разрешения по имени модели,
нет округления под сетку 32/64. Подготовка размеров под внутренние требования
модели, кадровая сетка и реальная исполнимость — ответственность workflow.

## 6. Результат и OpenAI API

Из ComfyUI history читаются файлы узла с `ND.v1.output`. Это адрес результата,
а не ограничение выполнения. Для видео берётся снимок исходного графа задания,
а не текущая конфигурация алиаса; статус можно получить после рестарта.
Задание автоматически повторно не отправляется.

Для изображений автор workflow обеспечивает PNG, включая реальный alpha
при transparent. Для видео автор обеспечивает файл, подходящий внешнему API
(для базового пакета — MP4/H.264). NeuralDeck не разбирает контейнер, кодек,
кадры и пиксели и не запускает дополнительные приёмочные проверки результата.

Обработка output_format=png|jpeg|webp и output_compression=0..100 для JPEG/WebP
остаётся общей функцией ответа NeuralDeck, потому что это параметры внешнего
OpenAI API. Это перекодирование по запросу клиента, а не проверка качества
или устройства workflow. response_format=url|b64_json также обрабатывает ND.
JPEG с явно запрошенным прозрачным фоном отклоняется как несовместимый запрос.

Внешние клиенты, включая LiteLLM, используют существующие endpoint и алиасы,
стандартные параметры, HTTP-ошибки и состояния задания. Метки ND.v1 и ID узлов
не добавляются в их запросы. Корректность работы модели и выполнения всех
возможностей графа подтверждается разработчиками workflow отдельно.

## 7. Подготовка и проверка пакета автором workflow

Автор готовит API-экспорты с контрактными входами и описание
поддерживаемых операций. Проверяет реальную генерацию, параметры, размеры,
количество результатов, seed, маску, прозрачность, FPS, формат и кодек у себя.
В NeuralDeck эти проверки во время конфигурации или генерации не повторяются.

Имена путей и моделей не участвуют в логике адаптера. Параллельные ветви разрешены.

Изменения реализованы в исходниках; сквозная проверка на целевом окружении
остаётся отдельной операцией. Сервер и работающие конфигурации автоматически
не изменялись.

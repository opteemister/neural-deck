# Идеи и задачи Neural Deck

В этом файле — только список задач: постоянный номер, тема, статус,
следующий шаг и ссылки на материалы. Обращаться к задаче можно по номеру или теме.
Завершённые и отложенные задачи сохраняем.

Подробности храним отдельно и создаём файлы по мере необходимости:
- `docs/tasks/TASK-001-<тема>.md` — описание идеи, вопросы и история решений;
- `docs/research/TASK-001-<тема>.md` — исследование и его результаты;
- `docs/specs/TASK-001-<тема>.md` — спецификация для согласования;
- `docs/results/TASK-001-<тема>.md` — результаты реализации и проверки,
  с отдельным указанием факта развёртывания.

Исследование и подготовку спецификации выполняем по поручению пользователя;
реализацию начинаем после согласования спецификации.

Статусы: `Идея` → `Исследование` → `На согласовании` → `Согласовано` →
`В работе` → `Готово`. Дополнительно: `Отложено`, `Отменено`.

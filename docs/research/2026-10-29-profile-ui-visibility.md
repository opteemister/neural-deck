# Проверка видимости настроек редактора профиля

Дата: 2026-10-29. Область: ProfileData, ProfileEditor, сохранение и запуск
профиля. Это проверка конкретного редактора, не полный аудит всех страниц MCP.

## Исправлено в текущем изменении

- `port` появился как редактируемое поле слева под командой запуска.
- `profileToForm` больше не заменяет `{{port}}` на число.
- Отдельный port сохраняется в запросах создания, изменения и запуска без
  сохранения, включая явный null при очистке.
- Из схемы убрано автоматическое заполнение пустого port значением 8188 для
  image/ComfyUI. Preview и запуск требуют значение, если команда содержит
  `{{port}}`.
- Явный port имеет приоритет в карточке. Кэш портов удалён.

## Остальные найденные расхождения для обсуждения

| Настройка или действие | API/MCP/конфигурация | Редактор |
|---|---|---|
| Draft-модель | `model.draft_path` | Читается и сохраняется, поля выбора нет |
| Типы задач | `types`, override определения движка | Читаются и сохраняются, controls нет |
| Протокол API | `api.protocol` | Читается и сохраняется, control нет |
| API URL | `api.base_url` | Читается и сохраняется, поля нет |
| URL интерфейса движка | `ui_url` | Читается и сохраняется, поля нет |
| Переименование профиля | PUT поддерживает новое name с сохранением profile_id | Имя существующего профиля readOnly |
| Флаги метрик | `enable_command_metrics` меняет command при сохранении и запуске | Есть галочка и hint, но результат изменения не показан перед сохранением |
| Нормализация пути модели | Выбор по эквивалентному пути | useEffect может изменить form.modelPath при открытии |

Источник: frontend/src/pages/profiles.tsx (FormState, ProfileEditor,
profileToForm, formConfiguration); backend/app/schemas/profiles.py;
backend/app/profiles/repository.py (put, enable_command_metrics);
backend/app/api/profiles.py (start_configuration).

## Решение пользователя 2026-10-29

Предложение расширить форму отклонено. Типы задач, API-протокол, API URL и UI URL
принадлежат только определению движка; overrides удалены из ProfileData,
контрактов API/MCP и frontend. `model.draft_path` и `{{model_draft}}` удалены:
путь draft-модели задаётся непосредственно в команде, в синтаксисе движка.
Порт сохранён как отдельная видимая настройка. Миграция существующих YAML
не выполняется по прямому указанию пользователя; код миграции не добавлен.

Переименование, нормализация пути модели и отображение флагов метрик — отдельные
найденные вопросы, не часть удаления profile overrides.
